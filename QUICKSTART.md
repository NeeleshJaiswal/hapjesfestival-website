## 🆘 Problemen Oplossen

### Afbeeldingen laden niet:
```
Check: Zijn afbeeldingen in de "images" map?
Check: Kloppen de bestandsnamen exact? (hoofdlettergevoelig!)
Fix: Upload de hele map opnieuw
```

### Countdown werkt niet:
```
Check: Is de datum in het juiste formaat? YYYY-MM-DD
Check: Browser console (F12) voor foutmeldingen
Fix: Pas datum aan in script.js regel 41
```

### Website niet responsive op mobiel:
```
Check: Test in browser mobiele modus (F12 → telefoon icoon)
Check: Clear browser cache (Ctrl+Shift+Del)
Fix: Herlaad pagina (Ctrl+F5)
```

### Menu werkt niet op mobiel:
```
Check: JavaScript geladen? (kijk browser console)
Fix: Upload script.js opnieuw
Test: Klik op hamburger menu (drie streepjes)
```
