## ✏️ Editing Text (Simple)

If you want to change text BEFORE putting the website online:

**Step 1:** Find the file `index.html`

**Step 2:** Right-click → "Open with" → Choose "Notepad" or "TextEdit"

**Step 3:** Find the text you want to change (Ctrl+F or Cmd+F)

**Step 4:** Modify the text

**Step 5:** Save (Ctrl+S or Cmd+S)

**Step 6:** Upload to Netlify

**⚠️ Note:** Only change text between `>` and `<`

Example:
```html
<p>This is the old text</p>
```
Becomes:
```html
<p>This is the new text</p>
```
